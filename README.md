# 像素婚禮 GitHub Pages 上傳包

最新版含九種髮型、六種膚色、兩種眼型及自由調色，雙人同行、婚禮動畫與舞台紀念合照均保留。

1. 解壓縮 ZIP。
2. 在 GitHub 建立 Public 儲存庫。
3. 把解壓後所有檔案直接上傳至儲存庫最外層，直接看得到 index.html；不要上傳 ZIP 本身。
4. Settings → Pages → Deploy from a branch → main → / (root) → Save。
5. 等待部署完成，再按 Visit site 取得分享網址。

更新既有 GitHub 網站：上傳此包所有檔案並覆蓋同名檔案，保留大小寫。這次需包含 extra-styles.png 及 twin-hair.png。
如找不到 .nojekyll，可在儲存庫根目錄建立同名空白檔案。
請用網站網址遊玩；直接雙擊本機 HTML 可能受到瀏覽器安全限制而無法調色或匯出照片。
雙人模式是同一支手機上的兩位同行角色，非跨裝置連線。
