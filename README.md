## 貼紙祝福板

GitHub Pages 僅提供靜態檔案，不能直接保存所有訪客共用的貼紙。此版本的祝福板會連往婚禮網站的共用祝福板，貼紙保存在該網站的資料庫。訪客需要該婚禮網站的存取權限。其他遊戲功能可直接使用。
