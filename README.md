# 伊薩克與白暝的像素婚禮

包含最新版自由調色、單人／雙人同行、婚禮動畫、宴會廳，以及舞台紀念合照。

## 上傳步驟

1. 解壓縮 ZIP。
2. 在 GitHub 建立 Public 儲存庫，例如 pixel-wedding。
3. 將解壓後全部檔案上傳至儲存庫最外層，直接看得到 index.html。不要上傳 ZIP 本身，也不要再套一層資料夾。
4. 進入 Settings → Pages。
5. Source 選 Deploy from a branch；Branch 選 main；Folder 選 / (root)，按 Save。
6. 等待發布完成，按 Visit site 取得遊玩網址並分享。

若看不到 .nojekyll，可在儲存庫根目錄建立同名空白檔案。

## 使用注意

不需要安裝套件、API 金鑰或資料庫。手機點入場後開始播放音樂。
雙人模式為同一支手機的兩位同行角色，非跨裝置連線。
離開婚禮可產生及下載紀念合照，也可長按儲存。
更新時替換同名檔案即可，保留檔名大小寫。
請用 GitHub Pages 網址遊玩；直接雙擊本機 HTML 可能受到瀏覽器限制而無法調色或匯出照片。
